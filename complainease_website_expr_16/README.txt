ComplainEase — Internet Programming Lab Experiment
===================================================

HOW TO RUN
1. Extract complainease_website.zip.
2. Open the complainease_website folder.
3. Double-click index.html or open it in Chrome, Edge, or Firefox.
4. No server or database is required for this front-end prototype.

DEMO LOGIN ACCOUNTS
User: user@complainease.demo / user123
Officer: officer@complainease.demo / officer123
Admin: admin@complainease.demo / admin123

FEATURES
- User registration and login
- Submit complaint with category, priority, description, and attachment filename
- Map-style location marker (demo illustration)
- Complaint ID generation, status tracking, and complaint history
- Add additional complaint information
- Officer workspace: view complaints, update status, add notes and proof-of-work descriptions/files
- User feedback on resolved complaints
- Sample administrator contact details
- Admin account creation/deletion, password changes, and officer credential generation
- Admin feature visibility toggles and portal information management
- Common issues and solutions FAQ
- Responsive desktop/mobile layout

LIMITATIONS
This is a front-end lab prototype. Records reset when the page reloads. Attachments are not uploaded to a server;
only filenames are displayed. The map is an illustration and does not connect to Google Maps. Email/SMS alerts,
secure authentication, role-based server authorization, database persistence, and real file storage are simulated
or not implemented. A production version requires backend APIs, a database, secure access control, and a valid
Google Maps API key for live maps.
