EasyToll — Internet Programming Lab Experiment 15
=================================================

HOW TO RUN
1. Extract easytoll_website.zip.
2. Open the easytoll_website folder.
3. Double-click index.html or open it in Chrome, Edge, or Firefox.
4. No Node.js or database is required for this front-end demo.

DEMO LOGIN ACCOUNTS
Driver/User: user@easytoll.demo / easy123
Admin: admin@easytoll.demo / tolladmin123
Toll gate operator: gate@easytoll.demo / gate123

FEATURES
- User registration and login
- E-wallet top-up demo
- Vehicle detail management
- Advance toll eTicket purchase and QR illustration
- Toll pass application and renewal
- Admin approval of passes and QR illustration
- Toll gate console: verify pass/ticket IDs and update location
- Gate operator account management
- Toll detail creation/deletion
- Recurring routes and reminder toggle
- Automatic payment toggle (demo)
- Transaction history and CSV export
- Responsive desktop and mobile layout

LIMITATIONS
This is a front-end lab prototype. Data is held in JavaScript memory and resets on refresh.
Payments, recurring payments, real QR scanning, toll authority APIs, SMS/email notifications,
secure authentication and database persistence are simulated. QR patterns are illustrations,
not scannable QR codes. Real deployment requires a backend, database, payment gateway,
secure authentication and integration with toll-gate systems.
