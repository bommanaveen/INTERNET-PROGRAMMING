GLOW STUDIO — BEAUTY PARLOUR APPOINTMENT BOOKING
Internet Programming Lab project
Technologies: HTML5, CSS3, JavaScript (Vanilla)

FILES
- index.html : website pages, forms, booking and feedback dialogs
- style.css  : responsive styling for desktop and mobile
- script.js  : service catalogue, accounts, booking calendar, slot availability,
               manager portal, blocked time slots, reservation history and feedback

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a modern browser, or open the folder in VS Code and use Live Server.

CUSTOMER FEATURES
- Register/sign in
- Search and filter services, sort by price
- Select stylist, date, and available time
- Book, reschedule, or cancel appointments
- Personal profile, upcoming reservations and booking history
- Leave feedback after a booking is marked Completed

MANAGER / STAFF FEATURES
- View appointments by date and stylist
- Add appointments, edit reservations and update statuses
- View customer contact details for calling/SMS from the user's own device
- Block and unblock unavailable stylist time slots
- Add or remove salon services
- View customer feedback

IMPORTANT LIMITATIONS
This is a front-end demonstration using localStorage. It does not provide shared,
real-time multi-user booking, server-side authentication, actual SMS/calling,
email reminders, or payment processing. Browser-local storage is not a secure
database. Online payment is demo-only. A production system needs a backend and
database, secure authentication, server-side slot locking, an email/SMS provider,
and a payment gateway.
