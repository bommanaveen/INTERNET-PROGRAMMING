HOME FINDER — REAL ESTATE SEARCH WEBSITE
Internet Programming Lab Experiment

FILES
- index.html: website structure
- style.css: responsive visual design
- script.js: sample property listings, filters, accounts, saved searches, favorites, agents, viewing requests and valuation
- README.txt: instructions and limitations

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a current web browser.
3. Internet access is recommended for Google Fonts and property photos.

FEATURES
- Friendly home page with Buy, Rent and Commercial search
- Property listings with images, details, price, type, location, size and amenities
- Search by location/keyword, budget, property type and purpose
- Save favorite properties and saved search criteria
- Buyer registration and login
- Viewing appointment request form
- Agent and real-estate company search, plus demo enquiries
- Map-style preview and Google Maps search links for property locations
- Simple illustrative property valuation calculator
- Property submission form for demonstration
- Website visit records and sample property data in localStorage

IMPORTANT LIMITATIONS
This is a frontend-only lab demo. Data is stored in browser localStorage, not a server database. Passwords are not securely hashed. Map view is a visual demo with links to Google Maps, not an embedded live Google Maps API. No real notification, email, agent communication, transaction, title verification, or booking confirmation is sent. Do not enter real passwords or sensitive data. A production system needs a secure backend/database, hashed credentials, access control, a real mapping API, and appropriate property verification.

All prices and listings are sample demonstration data. Verify all real estate information independently.
