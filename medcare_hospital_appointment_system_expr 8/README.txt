MEDCARE HOSPITAL APPOINTMENT BOOKING SYSTEM
Internet Programming Lab Project
Technologies: HTML5, CSS3, JavaScript (Vanilla)

FILES
- index.html: Home page, doctor listings, booking and check-in dialogs
- style.css: Responsive layout and styling
- script.js: Search, filters, demo accounts, appointment booking, cancellation,
  rescheduling, patient history, check-in details, reviews, admin dashboard,
  doctor management, appointment statistics, blocked time slots and map links

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Or open this folder in VS Code and run index.html with Live Server.

PATIENT FEATURES
- Register/login
- Search doctors by name, specialty, hospital and location
- Sort by rating or consultation fee
- View doctor profiles and open Google Maps search links
- Book, reschedule, and cancel appointments
- View appointment status and history
- Submit a patient check-in form
- Update personal details
- Rate and review doctors

ADMIN FEATURES
- Manage doctors (add/remove)
- View and update appointment statuses
- View appointment statistics
- View ratings and written feedback
- Block/unblock doctor time slots

IMPORTANT SAFETY / TECHNICAL LIMITATIONS
This is a front-end educational demonstration only. Data is stored in the current
browser's localStorage and is not a shared, secure, multi-user database. Passwords
are not securely hashed. Do not enter real patient details or medical information.
No real email/SMS reminders or payments are sent or processed. For a real hospital
deployment, implement a secure backend, role-based access control, encrypted
database, audit logs, server-side availability locking, privacy and healthcare
regulatory review, and approved email/SMS integrations. The Google Maps button
opens a Google Maps search URL for the demo hospital and city.
