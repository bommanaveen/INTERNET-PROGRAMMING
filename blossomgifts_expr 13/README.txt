BLOSSOMGIFTS - FLOWERS AND GIFT ORDERING WEBSITE
Internet Programming Lab Experiment / Use Cases

FILES
- index.html: website structure and home page
- style.css: responsive styling
- script.js: product catalogue, account demo, cart, checkout, order tracking and admin tools

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Browse categories, search gifts, filter and sort products.
4. Add products to your bag. Create an account, then complete a demo checkout with recipient and scheduled delivery details.
5. Click the account icon to view demo orders and delivery status.
6. Click "Admin demo" in the footer. Demo password: blossom123.

FEATURES
CUSTOMER
- Browse all product categories and subcategories from the home page
- Search, filter and sort products by category and price
- View product descriptions and photos
- Save favourites
- Register/login demo
- Add products to cart and place demo orders
- Choose recipient, delivery date/time and gift message
- View order confirmation and local order tracking
- Join a simulated newsletter list

ADMIN
- Add new products
- Edit product prices
- Remove admin-added products
- View customer checkout information and order details

IMPORTANT LIMITATIONS
- Frontend-only lab prototype. Data is stored in browser localStorage, not a shared database.
- Login is a demonstration, not production-secure authentication. Do not use real passwords.
- No real payment is taken. Email/SMS confirmation is not sent; the website displays a local demo confirmation.
- Product photos are loaded from Unsplash and need an internet connection.
- Real-time delivery tracking, email/SMS and secure payments require a backend, database, payment gateway, messaging provider and delivery integration.
- Admin demo password is visible in this README and is only for classroom demonstration.
- Keyboard shortcut Alt+Shift+A also opens the admin login.
