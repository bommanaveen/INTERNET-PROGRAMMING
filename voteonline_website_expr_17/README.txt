VoteOnline — Internet Programming Lab Experiment
=================================================

HOW TO RUN
1. Extract voteonline_website.zip.
2. Open the voteonline_website folder.
3. Double-click index.html in a modern browser.
4. No server or database is required for this front-end demo.

FEATURES
- Voter ID and date-of-birth demo validation
- OTP verification (demo OTP is shown on screen)
- Candidate directory and candidate selection
- Vote submission confirmation and ballot receipt
- Duplicate vote prevention in the current browser session
- Voter voting history without exposing candidate selection
- Aggregate demo election results and CSV export
- Admin candidate and election management
- Voter list creation, ward allocation, editing and deletion
- CSV voter list import
- Admin election results dashboard
- Responsive layout for desktop and mobile

IMPORTANT LIMITATIONS
This is a front-end lab prototype. Data resets when the page is reloaded.
The OTP is displayed for demonstration and is not sent by SMS/email. Authentication,
vote storage, encryption, eligibility checks and result publication are not production-secure.
Do not use this prototype for a real election. A real deployment needs a secure backend,
database, independent election-security review, audited ballot secrecy and reliable access controls.
