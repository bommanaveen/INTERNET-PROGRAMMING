ONLINE CAKE ORDERING SYSTEM
Internet Programming Lab Project
Technologies: HTML5, CSS3, JavaScript (Vanilla)

FILES
- index.html : page structure and dialogs
- style.css  : responsive styling
- script.js  : product catalogue, search/filter, cart, authentication demo,
               checkout demo, customer orders, admin product/order management

HOW TO RUN
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. For the best experience, use VS Code with the Live Server extension.

FEATURES
Customer:
- Register and login
- Search cakes and filter by category, flavor, and maximum price
- View cake details and choose size/message
- Add/remove cart quantities
- Enter shipping address and place demo order
- View order history and delivery progress

Admin:
- Login using the demo admin credentials
- Add, edit, and delete cake products
- Manage inventory quantities
- View orders and update delivery status

IMPORTANT LIMITATIONS
This is a front-end lab demonstration. Data is saved in the current browser using
localStorage, so it is not a shared multi-user application and may be cleared by
the browser. Passwords are stored only for demonstration and are NOT secure.
There is no real payment gateway, email service, server-side authentication,
database, or real image upload. Online payment is explicitly demo-only.
For a production application, add a backend (for example Node.js/Express or
Spring Boot), database (MySQL), secure password hashing, validation, image
storage, email provider, and a payment provider such as Razorpay/Stripe.
