STYLEHUB — ONLINE FASHION STORE
Internet Programming Lab Experiment

FILES
- index.html: website structure
- style.css: responsive layout and visual styling
- script.js: catalogue, cart, wishlist, login, checkout demo, orders and admin functions

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet access is recommended for Google Fonts and product photos.
4. For best results, use Chrome, Edge, or Firefox.

FEATURES
- Home page with category and subcategory navigation
- Search, category/subcategory filtering, sorting
- Product details, image, description, size options, ratings and reviews
- Cart add/edit/remove and stock checks
- Customer registration and login
- Wishlist
- Demo checkout with delivery details and STYLE15 discount code
- Order history and status tracking
- Admin product add/edit/delete, price/description/stock management
- Admin view of customers and checkout/order details, order status updates
- Responsive desktop/mobile layout

IMPORTANT LIMITATIONS
This is a frontend lab demonstration using browser localStorage. Login passwords are not securely stored, and data exists only in the current browser. No real payment gateway, order email, server, database, or shipping integration is connected. Do not use real customer or payment information. A production deployment needs a secure backend, database, authentication, and payment provider.

The site uses remote image URLs. If a photo does not load, check internet access.
