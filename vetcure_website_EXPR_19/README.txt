VetCure - Veterinary Care Connect
=================================

PROJECT
VetCure is a responsive front-end prototype for a farmer-to-veterinarian consultation platform.

FILES
-----
index.html  - Page structure
style.css   - Responsive styling
script.js   - Farmer and doctor demo workflows

RUN
---
1. Extract vetcure_website.zip.
2. Open the vetcure_website folder.
3. Double-click index.html to open it in a modern browser.
4. No server or database is required for this prototype.

FARMER FEATURES
---------------
- Registration, login, demo OTP verification (123456)
- Post animal health complaints with text symptoms
- Select a doctor and see public government CVH or private clinic fees
- Attach image/audio/video files using the browser file picker
- View complaint status and doctor responses
- View VetCure details, doctor profiles, news, sample reports
- Post feedback and view demo payment records
- Profile editing

DOCTOR FEATURES
---------------
- Demo doctor login / registration and OTP UI
- View farmer complaint records and symptom details
- Post a response and update request status
- Manage educational cure-library content and news
- View user details, payment details and feedback
- Edit a sample doctor profile with bank / EasyPaisa placeholder fields

PAYMENT MODEL IN THE DEMO
-------------------------
- Government CVH doctor subscription is free.
- Private clinic profile shows a sample consultation fee.
- Bank transfer and EasyPaisa options are represented in the demo form.
- No actual payment is taken or processed.

IMPORTANT LIMITATIONS
---------------------
- Front-end only: there is no backend or database.
- All data exists in browser memory and resets on refresh.
- File names are displayed, but uploaded video/audio/images are not transmitted or stored.
- OTP is shown as a demo code; no SMS/email is sent.
- No real payment gateway or bank connection is implemented.
- Sample doctors, news, care notes and chart percentages are illustrative.
- Educational care information is not a diagnosis. A licensed veterinarian should assess animals and prescribe treatment.
