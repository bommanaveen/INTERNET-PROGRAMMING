TECHSAVVY ONLINE ELECTRONICS SHOP
Internet Programming Lab Project
Technologies: HTML5, CSS3, Vanilla JavaScript

FILES
- index.html : storefront, categories, shop, cart drawer, login, checkout
- style.css  : responsive design
- script.js  : product catalogue, filtering, cart, wishlist, customer accounts,
               checkout, order history/tracking, admin catalogue and order management
- README.txt : this guide

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Or open the folder in VS Code and use the Live Server extension.

CUSTOMER FEATURES
- Register/login
- Browse home page categories and subcategories
- Search products and filter by category / availability
- Sort by price or rating
- View product descriptions, stock, and reviews/rating summary
- Add/remove wishlist items
- Add products to cart and change quantities
- Checkout with sample shipping details and demo payment selection
- View order history and track order status

ADMIN FEATURES
- Add, edit, and remove products
- Update price, old price, description, category, subcategory, brand and stock
- View customer checkout details
- Update order status

IMPORTANT LIMITATIONS
This is a front-end lab demo using browser localStorage. It is not a shared
multi-user store, and passwords are not securely hashed. No real payment gateway,
email transaction, shipping carrier, or recommendation engine is integrated.
For production use, build a backend and database, secure authentication, payment
provider integration, server-side stock validation, email notifications, and
appropriate privacy/security controls. Product visuals use emoji placeholders.
