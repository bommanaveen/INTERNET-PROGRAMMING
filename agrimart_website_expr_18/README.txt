AgriMart - Internet Programming Lab Experiment 18
===================================================

ABOUT
AgriMart is a responsive front-end demonstration of an online agricultural supplies marketplace. It includes a product catalog, customer shopping flow, wallet simulation, shipping address management, order tracking, and a farmer seller portal.

FILES
-----
index.html  - Page structure and content
style.css   - Responsive layout and visual styling
script.js   - Product search/filtering, cart, wallet, checkout, orders, and farmer tools

HOW TO RUN
----------
1. Extract agrimart_website.zip.
2. Open the agrimart_website folder.
3. Double-click index.html to open it in a modern browser.
4. For best results, use Chrome, Edge, or Firefox. No server or database is required.

FEATURES
--------
PUBLIC / CUSTOMER
- Customer registration and login UI
- Demo OTP verification (OTP: 123456)
- Search products by name, category, or description
- Filter by category and sort by price
- View product details and safety notes
- Add products to cart, change quantities, and remove items
- Manage demo wallet balance
- Add and delete shipping addresses
- Place demo orders using wallet balance
- View order details and order/shipping status
- Customer support inquiry form

FARMER / SELLER
- Farmer login and registration UI with demo OTP
- Add, edit, and delete products
- Set product name, category, price, unit, description, badge, and emoji
- Manage customer order and shipping status
- View demo sales summary

LIMITATIONS
-----------
- This is a front-end-only educational prototype.
- Data is stored in browser memory and resets when the page is reloaded.
- OTP is displayed for demonstration; no SMS or email is sent.
- Wallet payments are simulated; no real money is transferred.
- No real image upload, payment gateway, shipping carrier, backend, or database is connected.
- Do not use this demo for real agricultural purchases or financial transactions.
- Always follow product labels and local agricultural safety guidance when handling farm inputs.
